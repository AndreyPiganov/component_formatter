# Компоновщик иллюстраций

Веб-сервис собирает редактируемые SVG-композиции из каталога векторных объектов. Можно ввести заголовок или метафору, перечислить названия объектов или собрать сцену вручную. Редактор поддерживает перетаскивание, поворот, пропорциональное масштабирование, дублирование, удаление и смену порядка слоёв.

## Запуск

Из корня репозитория выполните команду и откройте [редактор](http://localhost:8080).

~~~bash
docker compose up --build
~~~

nginx отдаёт React и проксирует запросы к API NestJS. Compose монтирует папку `assets` в режиме чтения. Каталог загружается при старте. После замены файлов выполните команду `docker compose restart backend`. При пустом каталоге можно загрузить отдельные SVG через интерфейс.

Для запуска на другой машине передайте `assets/catalog.json` и `assets/library/` отдельно от репозитория. Если порт занят, укажите `APP_PORT` в `.env` по примеру из `.env.example`.

## Короткая демонстрация

| Сценарий | Текст | Формат и палитра | Пример |
| --- | --- | --- | --- |
| По названиям | книга, лампа, ручка, папка (фон) | 1000 × 1000, лавандовая | study-and-ideas.svg |
| По метафоре | Музыка, приложение и решение головоломки | 500 × 500, бирюзовая | music-and-puzzles.svg |
| По названиям | кошелёк, монета, смартфон (фон) | 1200 × 630, персиковая | digital-wallet.svg |

Выберите режим, введите текст и нажмите **Собрать**. Перетащите объект, выберите его слой, измените угол и продублируйте его. Смените размер холста или палитру, затем нажмите **Скачать SVG**. Три примера и скриншот редактора `editor.png` находятся в локальной папке `assets/demo/`.

## Как устроен каталог

- Из векторного листа Figma выделены десять объектов. У каждого есть главный и монохромный варианты для двух размеров. При выделении сохранены исходные контуры, их атрибуты и порядок. Рамка каждого файла задана через viewBox по границам объекта.
- NestJS загружает assets/catalog.json и файлы по указанным в нём относительным путям. Записи с одинаковым id представляют один и тот же объект в разной детализации. Пара detail и id должна быть уникальной. role принимает main или background, detail принимает detailed, simple или any.
- React хранит слои как ссылки на объекты каталога и их трансформации. Размер холста определяет вариант исходника. При экспорте каждый слой становится группой в SVG с собственными идентификаторами внутренних ресурсов.
- Подбор по названиям учитывает названия и теги, разделённые запятыми, точками с запятой или переносами строк. Суффикс (фон) выбирает монохромный вариант. Без ключа OpenAI режим метафоры ищет связанные теги. При наличии OPENAI_API_KEY в .env NestJS передаёт модели заголовок, названия и теги доступных объектов. Ответ ограничен их идентификаторами. Размещение на холсте рассчитывает редактор.

В бэкенде функциональные модули находятся в `backend/src/modules/`. Контроллеры принимают HTTP-запросы, сервисы ведут сценарии, репозиторий библиотеки читает каталог и SVG, а клиент OpenAI выполняет внешний запрос. Сцены, загруженные через интерфейс SVG и пользовательские палитры хранятся в состоянии React до перезагрузки страницы. Для сохранения результата редактор экспортирует SVG.

Пример записи в массиве catalog.json.

~~~json
[
  {
    "id": "book-main",
    "name": "Раскрытая книга",
    "source": "Набор Figma",
    "tags": ["книга", "чтение"],
    "role": "main",
    "detail": "detailed",
    "file": "library/detailed/main/book.svg"
  }
]
~~~

Палитра импортируется как JSON через кнопку загрузки рядом с заголовком **Палитра**. Массивы задают четыре фоновых и четыре дополнительных цвета для главных объектов. Порядок соответствует позициям в исходной палитре Figma. Фоновые объекты и холст используют только фоновые цвета.

~~~json
{
  "name": "Моя палитра",
  "background": ["#D7CDF5", "#AA9BF0", "#7864D7", "#181817"],
  "objects": ["#F9ECB0", "#F9A3AA", "#FFE3E1", "#FFFFFF"]
}
~~~

## Разработка

Для разработки без контейнеров нужен Node.js 24. Установите зависимости для обоих приложений, затем запустите API и React в отдельных терминалах. Откройте редактор на локальном порту 5173. Vite проксирует API на локальный порт 3000.

~~~bash
npm --prefix backend ci
npm --prefix frontend ci
npm --prefix backend run dev
npm --prefix frontend run dev
~~~

~~~bash
npm --prefix backend test
npm --prefix frontend test
npm --prefix frontend run build
~~~

AI-инструменты проекта включают Codex для реализации и проверок и опциональный OpenAI Responses API для подбора существующих объектов по смыслу.

Исходный код проекта хранится в [репозитории component_formatter](https://github.com/AndreyPiganov/component_formatter).
